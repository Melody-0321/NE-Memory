## 三、核心发现

### 3.1 能力三角：不存在全维度最优

- **BM25**：窄窗口精度（P@5=0.450）、叙事型查询
- **纯向量**：排序质量（NDCG/MRR/Hit@5）、首条命中（12 条中 11 条 Hit@5）、目标型查询
- **RRF**：宽召回（R@20=0.871），但中等深度存在塌陷

### 3.2 不对称互补

| | 叙事型 P@10 | 目标型 P@10 |
|---|---|---|
| BM25 | 0.283 | 0.283 |
| Vector | 0.267 (-5.9%) | **0.317 (+11.8%)** |
| RRF | 0.267 (-5.9%) | 0.283 (0%) |

- 向量在目标型上的增益（+11.8%）远大于 BM25 在叙事型上的护城河（+5.9%）
- 纯向量替代 BM25 的代价可控（叙事型 -5.9%），但反向代价更大（目标型 -11.8%）

### 3.3 RRF "中等深度塌陷"

RRF P@10=0.275 低于 BM25 (0.283) 和纯向量 (0.292) —— 两路排名不一致时，融合产生的折中排名在 Top10 窗口内反而稀释了好结果。

**典型退化案例**：
- Query #5 stm_29: BM25#10 → 向量#22 → RRF#17（BM25 的好排名被向量拖累）
- Query #8 stm_27: BM25#9 → 向量消失 → RRF#24（BM25 的优势完全丢失）
- Query #12 整体坍缩: P@10 从 BM25 0.200 跌到 RRF 0.000

### 3.4 GT Rank 追踪的价值

`__ne_debug_rank_map` 让每个 GT 条目在三轮中的精确位置可见。这直接证实了退化案例的根因（噪声稀释 + 排名不一致），而非随机波动。

### 3.5 查询类型的语义鸿沟

- **叙事型**：场景/动作锚点 → 关键词密集 → BM25 天然优势
- **目标型**：抽象概念/人物属性 → 需要语义泛化 → 向量天然优势

Query #9 "江岚创作状态" 是最极端的案例：
- BM25 P@10 = **0.000**（完败，关键词"创作状态"在语料中无精确匹配）
- Vector P@10 = **0.400**（bge-m3 正确关联到 stm_06/09/16）

## 四、RRF k 值调优结果

### 4.1 密集扫描 (27 points, k=20-200)

发现 **三段相位结构**：

```
k ≤ 102:     ━━━ 低台 NDCG=0.662, P@10=0.275
k ∈ [105,138]: ━━━ 高台 NDCG=0.669, P@10=0.283, P@10 Tgt=0.300
k ≥ 140:     ━━━ 衰退 NDCG=0.660→0.655
```

### 4.2 两个精确临界点

| 边界 | 位置 | 现象 |
|------|------|------|
| 上升沿 | k=102→105 | NDCG 0.662→0.668, P@10 Tgt 0.283→**0.300** |
| 下降沿 | k=138→140 | NDCG 0.669→0.660, P@10 0.283→0.275 |

### 4.3 高台极其平坦

k=105 到 k=138 共 34 个整数值，NDCG@10 稳定在 0.668-0.669，波动 <0.001。RRF 在此区间对 k 不敏感。

### 4.4 选值

**k=110**（高台正中，整数）。相对 k=60：
- NDCG@10: +0.9% (0.662→0.669)
- P@10 目标型: +6.0% (0.283→0.300)
- R@10: +1.4% (0.694→0.704)

### 4.5 k=60 与 k=110 分类型对比

| | k=60 | k=110 | 变化 |
|---|---|---|---|
| P@10 Narrative | 0.267 | 0.267 | 0% |
| P@10 Targeted | 0.283 | **0.300** | **+6.0%** |
| NDCG@10 Narrative | 0.909 | 0.909 | 0% |
| NDCG@10 Targeted | 0.416 | **0.428** | **+2.9%** |

增益完全集中在目标型查询，叙事型不受影响。

## 五、技术栈评估

### 值得添加
- **查询类型分类器**：叙事 → BM25，目标 → 向量，各自最优
- **纯向量为主路径**：排序质量最高，Hit@5=0.917

### 值得考虑切除
- **RRF 融合层**（争议项）：仅 R@20 有优势，P@10 反而不如单路；如果目标场景是 Top5/Top10 注入，RRF 可能是过度工程
